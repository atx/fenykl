# Example plugins

Build one with `uv run fenykl plugin build sdk/projects/<name>`. Kept are the product plugin, the
smallest example and the bird detector.

| project | what it is |
|---|---|
| `main/` | the daily-use plugin (focus distance, depth of field, focus meter, battery percentage, Fn screenshot, R/B swap, settings page); reference user of the cfg, log, ui, HUD, key and shot libraries; names no firmware symbol: camera state through `include/body.h`, features per body capability (`plugin.toml`), screen layout per camera in `main_layout.h`. E-M10 II: logging, the saved settings (cfg), the settings page from the Custom K Eye-Fi row (option "Log level") and the battery percentage on the basic and histogram INFO screens (hidden in MENU, the Super Control Panel and playback); no Fn override (`key` capability off) |
| `hello/` | smallest plugin: writes `C:\FENYKL.LOG` and returns; the first plugin to try after flashing (E-M10 II: through the log library) |
| `birddetect6/` | the bird detector wide-k326-pot-r7 (32-channel trunk), trained on birds down to 0.1 of the frame height: colour input from an IPU engine-1 resize of the live view to 96x72 YUYV (skipped during still capture and while engine 1 is locked), the network on CPU1 as generated code (power-of-two weights (0, +-1, +-2, +-4) in the add/sub layers, compiled as add/sub taps in Horner order by magnitude (the +-4 taps, both 16-bit lanes doubled, the +-2 taps, doubled, the +-1 taps), the bias folded into a per-channel `udf00` multiplier epilogue, split into I-cache-sized blocks of output channels, L6-L8 in 7 blocks), one fire decision per frame on the sum of the presence channel against a threshold and a 3x3 centroid point around the top heat-map cell, steers the face frame to that point every frame; a short Fn press in live view or the menu saves a screenshot of the panel with the face frame on the bird (`C:\SHOTnnnn.PPM`, shot library, in a task below the detector's so detection goes on; long Fn stays stock); `gen_model.py --handoff` regenerates every model-dependent source and the simulator vectors from a fenykl-nn handoff directory. Weights trained by the separate fenykl-nn project on the Open Images Dataset V7 bird class (annotations CC BY 4.0, Google LLC; images listed as CC BY 2.0) and iNaturalist Open Data bird photos (licensed per photo: CC0, CC BY or CC BY-NC) |
